# M4 Eve Dock Surface

**Status:** implemented; live-model acceptance pending local credential

The native Mac app now has one promoted dock species: **Eve**. Clicking it
performs this ordered, governed operation:

```text
Swift dock click
  → Kernel tile.create + worker.create
  → native AgentOS Eve session attach
  → Kernel worker.runtime.bind
  → Swift Eve session sheet
```

The Kernel persists the actor and AgentOS session identifiers on the worker;
the session sheet keeps only display transcript entries. It cannot create a
second workflow-state store.

## Verified without credentials

- `swift build` and `swift run QuantFlowKernelProof` pass. The proof verifies
  runtime binding survives a Kernel snapshot.
- Native sidecar `POST /v1/agentos/eve-session` creates a real Eve ACP session
  for `["m4-proof", "eve-tile-a"]` and returns HTTP `201`.
- A prompt without `OPENCODE_GO_API_KEY` returns HTTP `409` with an explicit
  explanation. The Swift UI displays that error; it never calls this state
  promptable.

## Required final M4 proof

Set `OPENCODE_GO_API_KEY` in the environment that starts the local runtime,
then launch the app and verify: dock click → Eve tile/session sheet → one real
reply. Record click-to-input readiness and fail the rung if it exceeds two
seconds. The current machine has no key, so that final model-turn claim is not
made here.
